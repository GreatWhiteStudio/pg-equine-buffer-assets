# P&G Equine Buffer Assets

Public hosting repository for approved P&G Equine & Co. LTD social-media images only. Files may be referenced by scheduled Buffer posts.

Production assets are stored under `social/<ISO-week>/` with immutable filenames containing a short SHA-256 fingerprint. Once a URL has been used, its binary must never be overwritten; corrected assets receive a new filename.

This repository must not contain internal reports, SSOT material, CRM/contact data, automation prompts, credentials, rejected generations or source design files.
